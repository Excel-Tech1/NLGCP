# Scientific Integrity

NLGCP results require traceable inputs, configuration, software versions, reference frames, and validation datasets. Raw observations are immutable. Synthetic infrastructure fixtures must be conspicuously labelled and cannot support accuracy or coverage claims.

No centimetre-level result, ambiguity decision, atmospheric model, station threshold, coordinate, or correction quality may be asserted without documented evidence and appropriate Level 3 review. RTKLIB is the planned validated RTK foundation; PRIDE PPP-AR is an independent offline validation tool, not the production correction engine.
