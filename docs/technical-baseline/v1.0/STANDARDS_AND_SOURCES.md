# Standards and Technology Source Register

This file records authoritative references used to keep the baseline current. It is not a substitute for licensed RTCM specifications where those are required for implementation/compliance.

- IGS Formats and Standards: https://igs.org/formats-and-standards/ - includes RINEX 4.02, SINEX, SP3, Bias-SINEX, IONEX and SSR references.
- IGS RINEX Committee: https://igs.org/wg/rinex/ - RINEX 4 guidance and current format documents.
- IGS Real-Time Service Formats: https://igs.org/rts/formats/
- RTKLIB: https://github.com/tomojitakasu/RTKLIB
- PRIDE PPP-AR: https://github.com/PrideLab/PRIDE-PPPAR - repository showed v3.2.10 in July 2026 when this baseline was prepared.
- BKG Ntrip resources: https://igs.bkg.bund.de/ntrip/
- NATS JetStream: https://docs.nats.io/nats-concepts/jetstream
- PostgreSQL: https://www.postgresql.org/docs/current/
- PostGIS: https://postgis.net/
- FastAPI: https://fastapi.tiangolo.com/
- Prometheus: https://prometheus.io/docs/
- Docker Compose: https://docs.docker.com/compose/
- Kubernetes: https://kubernetes.io/docs/
