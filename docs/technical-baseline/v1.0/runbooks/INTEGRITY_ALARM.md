# Runbook: Correction Integrity Alarm

1. Treat as scientific incident; do not override alarm to preserve uptime.
2. Record stations, residuals, ambiguity state, model version and affected sessions.
3. Remove suspect station/model input if evidence supports it.
4. Recompute network eligibility.
5. Downgrade/stop affected mountpoint if uncertainty remains.
6. Replay incident window before re-enabling normal service.
